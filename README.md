# Alexgas73

منصة فيديو عالمية قيد التخطيط للبالغين (+18)، تجمع المشاهدين والناشرين الأفراد وشركات المحتوى ضمن تجربة موحدة لرفع الفيديو وإدارته واستضافته وتحقيق الإيرادات.

> **الحالة الحالية:** تأسيس المواصفات. وجود هذه الوثائق لا يعني أن التطبيق أو خدمات الفيديو أو الدفع قد بُنيت أو أُطلقت.

## نطاق المنتج المعتمد مبدئياً
- رفع الفيديو من الناشرين الأفراد عبر الهاتف أو الكمبيوتر.
- استقبال محتوى الشركات وإدارته ونشره بموجب اتفاق، أو تمكين الشركات الموثّقة من الرفع المباشر.
- التصفح والبحث وصفحات مشاهدة الفيديو والقنوات.
- لوحات منفصلة للناشرين والشركات والإشراف والمحاسبة والإدارة.
- إيرادات إعلانات للناشرين المؤهلين وعقود تجارية مستقلة للشركات.
- إمكانية إضافة الاشتراكات المدفوعة لاحقاً.
- دعم 25 لغة وRTL للعربية والفارسية والأردية.
- التحقق من العمر والحقوق والموافقات والخصوصية والإبلاغ عن المحتوى المخالف.

## أنواع الحسابات
1. مشاهد.
2. ناشر فردي.
3. شركة أو استوديو موثّق.
4. مشرف محتوى.
5. مدير مالي.
6. مدير عام للمنصة.

## مبادئ العمل
- لا تُعتبر الميزة مكتملة قبل تنفيذها واختبارها.
- لا تُعتمد نسب الأرباح أو مزودو الخدمات قبل دراسة التكاليف والشروط.
- لا يُنشر المحتوى لمجرد اكتمال رفعه؛ بل يمر بالمراجعة المطلوبة.
- تُفصل صلاحيات المحتوى عن الصلاحيات المالية والإدارية.
- تُسجّل الإجراءات الحساسة والتعديلات المالية في سجل تدقيق.
- المواصفات الحالية أساس قابل للمراجعة، وتُوثّق التغييرات اللاحقة.
- لا تُخزّن الأسرار أو مفاتيح API أو بيانات الدفع الحساسة في المستودع.

**التوثيق التأسيسي فقط.** لا يوجد في هذه المرحلة ما يثبت اكتمال واجهة المستخدم أو الخلفية أو استضافة الفيديو أو نظام الدفع أو جاهزية الإنتاج.
