# Alexgas73

منصة فيديو عالمية قيد التخطيط للبالغين (+18)، تجمع المشاهدين والناشرين الأفراد وشركات المحتوى ضمن تجربة موحدة لرفع الفيديو وإدارته واستضافته.

> **الحالة الحالية:** توثيق وتخطيط فقط. لا يثبت وجود التطبيق أو خدمات الفيديو أو الدفع. قرار الإصدار الأول موجود في طلب مراجعة مفتوح ولم يُدمج بعد.

## نطاق الإصدار الأول المخطط
- تجربة مجانية للمشاهدين في البداية؛ مع احتساب تكاليف الاستضافة والمعالجة ونقل البيانات ضمن التخطيط.
- إعطاء الأولوية للفيديو عند الطلب: رفع آمن، معالجة، مراجعة، ثم نشر بعد الموافقة — بعد تنفيذ هذه الخدمات واختبارها.
- رفع الناشرين الأفراد من الهاتف أو الكمبيوتر، ومسار محتوى للشركات الموثقة وفق الحقوق والعقود.
- التصفح والبحث وصفحات مشاهدة الفيديو والقنوات.
- واجهة البث المباشر قد تظهر للتعريف بالميزة، لكن البث الحقيقي معطّل وغير متاح.
- الاشتراكات والمشتريات المدفوعة والإعلانات المدرة للدخل ومشاركة أرباح الناشرين والتسويات الفعلية غير مفعّلة في الإصدار الأول.
- دعم 25 لغة وRTL للعربية والفارسية والأردية.
- التحقق من العمر والهوية والحقوق والموافقات والخصوصية والإبلاغ عن المحتوى المخالف.

## أنواع الحسابات
1. مشاهد.
2. ناشر فردي.
3. شركة أو استوديو موثّق.
4. مشرف محتوى.
5. مدير مالي.
6. مدير عام للمنصة.

## مبادئ العمل
- لا تُعتبر الميزة مكتملة قبل تنفيذها واختبارها.
- لا يُعتمد مزود فيديو أو استضافة أو دفع قبل التحقق من قبول نشاط المنصة وشروط الخدمة والتكلفة.
- لا يُنشر المحتوى لمجرد اكتمال رفعه؛ بل يمر بالمراجعة المطلوبة.
- تُفصل صلاحيات المحتوى عن الصلاحيات المالية والإدارية.
- تُسجّل الإجراءات الحساسة والتعديلات المالية في سجل تدقيق.
- لا تُخزّن الأسرار أو مفاتيح API أو بيانات الدفع الحساسة في المستودع.
- لا يبدأ اختيار أداة البناء قبل التأكد من أن شروطها تسمح بمشروع منصة محتوى للبالغين، ومن إمكانية نقل الكود والبيانات عند الحاجة.

## الحالة
**التوثيق التأسيسي فقط.** لا يوجد ما يثبت اكتمال واجهة المستخدم أو الخلفية أو استضافة الفيديو أو نظام الدفع أو جاهزية الإنتاج. راجع قرار الإصدار الأول وتقرير التدقيق قبل بدء التنفيذ.
