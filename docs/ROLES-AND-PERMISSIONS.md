# Alexgas73 — أنواع الحسابات والصلاحيات

**الحالة:** أنواع الحسابات معتمدة مبدئياً؛ المصفوفة التفصيلية تحتاج إلى مراجعة قبل التنفيذ. المنصة عامة وموجهة للجمهور العام. صلاحيات الدفع وتحقيق الدخل معطّلة في الإصدار الأول.

## 1. أنواع الحسابات

| نوع الحساب | الوظائف الأساسية |
|---|---|
| مشاهد | يتصفح ويبحث ويشاهد، ويتابع الناشرين ويحفظ المفضلة ويدير سجل المشاهدة وفق الخصوصية. |
| ناشر فردي | ينشئ قناته ويرفع فيديوهاته ويدير بياناتها ويتابع الإحصائيات. لا توجد أرباح أو دفعات فعلية في الإصدار الأول. |
| شركة أو استوديو | يدير حساب شريك موثّق وقناته وفريقه ويرفع المحتوى المتعاقد عليه ويتابع حالة المحتوى. |
| مشرف محتوى | يراجع الفيديوهات والبلاغات والحقوق، ويقبل أو يرفض أو يوقف المحتوى مع تسجيل السبب. |
| مدير مالي | دور مخطط للمرحلة اللاحقة؛ لا ينفذ دفعات أو تسويات فعلية في الإصدار الأول. |
| مدير عام | يدير الحسابات والصلاحيات والسياسات والإعدادات والتقارير ضمن سجل تدقيق، مع ضوابط تمنع تجاوز تعطيل الدفع أو البث. |

## 2. حدود الصلاحيات
- تُطبق الصلاحيات في الخادم وقاعدة البيانات، لا بمجرد إخفاء الأزرار.
- يُمنح المستخدم أقل قدر من الصلاحيات اللازمة.
- لا يحصل الناشر أو الشركة على صلاحيات إشرافية أو مالية عامة.
- لا يستطيع مشرف المحتوى تغيير الأرصدة أو تنفيذ الدفعات.
- لا يعتمد المدير المالي دفعة تخصه بنفسه دون ضوابط فصل المهام.
- تُطلب مصادقة إضافية للإجراءات الحساسة حيثما أمكن.
- تُسجل هوية المنفذ والوقت والهدف والنتيجة والسبب.
- تُراجع عضويات الشركات وتُسحب الصلاحيات عند انتهاء الحاجة.
- تعطيل الدفع يجب أن يُفرض خادمياً، حتى لو بقيت واجهات الأرباح ظاهرة كعناصر توضيحية.
- أي تفعيل مستقبلي للدفع أو البث يتطلب قراراً منفصلاً واختبارات قبول.

## 3. مصفوفة أولية

| العملية | مشاهد | ناشر | شركة | مشرف محتوى | مدير مالي | مدير عام |
|---|---|---|---|---|---|---|
| مشاهدة المحتوى المنشور | نعم | نعم | نعم | حسب الحاجة | حسب الحاجة | نعم |
| رفع محتوى | لا | لقناته | لقنوات الشركة | لا افتراضياً | لا | وفق صلاحية موثقة |
| تعديل القناة | لا | قناته | قنوات شركته | لا | لا | وفق صلاحية موثقة |
| مراجعة المحتوى | لا | لا | لا | نعم | لا | إشراف وفق السياسة |
| مراجعة البلاغات | إبلاغ | إبلاغ | إبلاغ | نعم | لا | إشراف |
| الاطلاع على مستحقات فعلية | لا | لا في الإصدار الأول | لا في الإصدار الأول | لا | غير مفعّل | لا في الإصدار الأول |
| طلب دفع فعلي | لا | لا | لا | لا | غير مفعّل | لا |
| اعتماد الدفعات الفعلية | لا | لا | لا | لا | غير مفعّل | لا |
| إدارة الأدوار | لا | لا | أعضاء شركته ضمن حدود | لا | لا | نعم مع سجل تدقيق |

هذه مصفوفة تأسيسية وليست تفويضاً نهائياً؛ يجب اعتماد الاستثناءات والضوابط قبل التنفيذ.

## 4. حالات الحساب والمحتوى
حالات حساب مقترحة: `pending_verification`, `active`, `restricted`, `suspended`, `closed`.

حالات فيديو مقترحة: `draft`, `uploading`, `processing`, `pending_review`, `approved`, `published`, `rejected`, `suspended`, `removed`.

تُحدد الانتقالات المسموحة ومن يملك تنفيذها وسبب القرار وإمكانية الاستئناف. لا يكفي وصول الفيديو إلى `approved` وحده لنشره إن كانت هناك ضوابط أخرى معلقة.

## 5. سجل التدقيق والاختبارات
يسجل تغيير الأدوار، وقرارات مراجعة المحتوى، وتقييد الحسابات، وتغيير العقود أو قواعد التوزيع، وإنشاء الدفعات واعتمادها، وتعديل إعدادات الأمان. يجب أن يكون السجل محمياً وأن تُحدد سياسة الاحتفاظ به.

اختبارات لازمة: منع المشاهد من استدعاء وظائف الإدارة؛ منع الناشر من رؤية بيانات ناشر آخر؛ منع الشركة من الوصول إلى شركة أخرى؛ منع المشرف من تنفيذ دفعة؛ منع إنشاء دفعات فعلية عند تعطيل الدفع؛ منع بدء جلسة بث فعلية عند تعطيل البث؛ وتسجيل كل تغيير حساس.
