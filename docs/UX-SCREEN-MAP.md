# Alexgas73 — خريطة الشاشات ومسارات الاستخدام

**الحالة:** مخطط وظيفي أولي؛ الهوية البصرية النهائية لم تُعتمد.

## 1. الشاشات العامة
- الصفحة الرئيسية والتصنيفات.
- نتائج البحث والفرز.
- صفحة مشاهدة الفيديو.
- صفحة القناة/الناشر.
- تسجيل الدخول وإنشاء الحساب.
- التحقق من العمر وإعدادات الخصوصية.
- السياسات والإبلاغ وطلب إزالة المحتوى.

## 2. مساحة المشاهد
- الملف الشخصي.
- القنوات المتابَعة.
- المفضلة.
- سجل المشاهدة.
- اللغة والخصوصية.

## 3. لوحة الناشر الفردي
- لوحة ملخص.
- رفع فيديو.
- قائمة الفيديوهات والمسودات.
- تفاصيل الفيديو وحالة المعالجة والمراجعة.
- الإحصائيات.
- الأرباح والتسويات.
- إعدادات القناة.

## 4. لوحة الشركة
- لوحة الشركة وإدارة القنوات.
- أعضاء الفريق والأدوار.
- مكتبة المحتوى ورفع/إرسال الفيديو.
- العقود والحقوق.
- الأداء والإيرادات والتسويات.

## 5. الإشراف والإدارة
- قائمة مراجعة المحتوى وتفاصيل القرار.
- البلاغات وطلبات الإزالة.
- إدارة الحسابات.
- اللوحة المالية وطلبات الدفع.
- السياسات والإعدادات.
- سجل التدقيق والتقارير.

## 6. قواعد التصميم
- هوية أصلية لـ Alexgas73، لا نسخ حرفي لواجهة منافس.
- أولوية للهاتف مع تصميم متجاوب للكمبيوتر.
- بحث وتنقل واضحان.
- إظهار الأزرار حسب الدور، مع فرض الصلاحيات أيضاً في الخادم.
- لكل عملية حالات تحميل ونجاح وخطأ برسائل مفهومة.
- أزرار الإبلاغ والخصوصية والسياسات سهلة الوصول.
- مراعاة التباين ولوحة المفاتيح وقارئات الشاشة وأهداف اللمس.
- لا نوافذ أو إعلانات مضللة أو تشغيل تلقائي غير متوقع.

## 7. صفحة مشاهدة الفيديو
المشغل، تشغيل/إيقاف، الصوت، شريط التقدم، الجودة عند توفرها، ملء الشاشة، الترجمة المصاحبة عند توفرها، العنوان والوصف، القناة والمتابعة، المفضلة والمشاركة والإبلاغ، والإفصاح عن الإعلان أو المحتوى المدعوم عند انطباقه.

## 8. مسار رفع الفيديو
1. فتح لوحة الناشر أو الشركة.
2. اختيار رفع الفيديو والملف.
3. إظهار تقدم الرفع وأي خطأ.
4. إدخال البيانات واللغة والتصنيفات.
5. تأكيد الحقوق والموافقات المطلوبة.
6. المعالجة وإنشاء الجودات.
7. عرض حالة المراجعة.
8. عرض القرار وسببه.
9. النشر بعد الاعتماد وإظهار الإحصائيات.

يجب عدم عرض اكتمال الرفع قبل تأكيد الخادم، ودعم استكمال الرفع عند انقطاع الشبكة إذا كانت الخدمة المختارة تسمح بذلك.

## 9. مسار الشركة والأرباح
الشركة: طلب شراكة ← تحقق ← اتفاق ← إعداد القناة والفريق ← رفع المحتوى وربطه بالحقوق ← مراجعة ونشر ← تقارير وتسويات.

الأرباح: فصل الإيرادات التقديرية عن المعتمدة للدفع، وإظهار الفترة والمصدر والرسوم والخصومات وأسبابها، وسجل الدفعات والاعتراضات. لا تُعدل الأرصدة مباشرة دون قيد مالي وسجل تدقيق.

## 10. اللغات
اختبار اللغات الـ25 المحددة في وثيقة المنتج، مع RTL للعربية والفارسية والأردية، والتأكد من عدم قص الأزرار أو كسر التخطيط بسبب طول النص.
